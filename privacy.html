Privacy policy

Last updated 30 October 2026

This policy covers this website and the app Deadlock Replays Uploader. Both belong to the owner of the YouTube channel Deadlock POV Replay Analytics.

The website

  • The site sets no cookies. It runs no scripts, analytics or ads, and has no forms.
  • GitHub Pages hosts it. GitHub logs each visitor's IP address for security purposes, as its privacy statement describes.

The uploader app

  • Deadlock Replays Uploader uses YouTube API Services.
  • Only the channel's owner uses it. No one else signs in to it.
  • It asks Google for one permission, to upload videos to the owner's channel. It reads no other data from the Google account.
  • It stores one sign-in key, an OAuth refresh token, in a file on the owner's own computer. It stores nothing anywhere else and places no cookies.
  • It sends video files and their details, such as title, description and privacy setting, to YouTube and to no one else.
  • It shares no user data with anyone. It shows no ads and lets no third party serve content.
  • Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Google handles data on YouTube under the Google Privacy Policy.

Removing access and data

  • You can revoke the app's access at any time on Google's security settings page.
  • On request, the stored key is deleted within 7 days. Deleting it does not change anything on YouTube. To remove a video, delete it on YouTube.

Contact

Send questions or complaints about these practices to deadlocktop1percentreplays@gmail.com.

Changes

If the app's use of data changes, this page changes first and shows a new date.
